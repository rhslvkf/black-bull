# 흑우키우기 — 비주얼 노벨 재설계 스펙

> 1차 버티컬 슬라이스(`2026-08-25-black-bull-design.md`)를 잇는 2차 설계.
> 게임 규칙 대부분은 그대로 두고, **장르 정체성과 화면 문법**을 다시 잡는다.

## 0. 무엇이 바뀌는가

1차 슬라이스는 "턴제 육성 + 주식 시뮬"로 만들어졌고 동작한다 — 156턴 완주, 엔딩 8종,
결정론, 610개 테스트. 그러나 화면이 게임의 정체성을 전달하지 못한다. 캐릭터는 검은 배경의
작은 SVG이고, 이벤트는 이모지 배지에 얹은 텍스트이며, 어떤 조작에도 화면이 반응하지 않는다.

**이 게임은 비주얼 노벨이다.** 주식은 이야기를 굴리는 기계장치이고, 플레이어가 이 게임을
하는 이유는 3년치 서사다. 그 전제로 화면을 다시 짠다.

동시에 1차에서 남은 게임플레이 결함 셋을 함께 고친다 — 행동 카드가 12장 상시 노출이라
선택이 무겁고, 스탯 5종이 화면에 아예 안 보이며, 매매 행위인 물타기가 주간 행동 한 칸을
잡아먹는다.

## 1. 장르 정체성

**비주얼 노벨 + 가상 주식.** 우선순위가 여기서 나온다.

- 이벤트 화면은 홈 화면과 **동등한 비중**을 갖는다. 부수적 팝업이 아니다.
- 조연 4인(박대박·최존버·김실장·엄마)은 화면에 인물로 등장한다. 이름만 언급되지 않는다.
- 여러 턴에 걸친 흐름(김실장 루트)이 화면에서 흐름으로 읽혀야 한다.
- 대사는 타이핑되어 나타난다.

이 스펙은 이벤트 **콘텐츠를 늘리지 않는다**. 76종을 그대로 두고 연출만 바꾼다.
분량 확대는 다음 이터레이션의 몫이다.

## 2. 성장 루프

1차의 스탯 5종은 각자 역할이 있으나 인맥만 비어 있었고, 어느 것도 화면에 보이지 않았다.

| 스탯 | 기존 역할 (유지) | 새 역할 |
|---|---|---|
| 분석력 | 적정가 밴드의 안개 | 분석 계열 카드의 **등급 확률** |
| 정보력 | 루머 선행 공개 | 정보 계열 카드의 등급 확률 |
| 강인함 | 멘탈 하락 저항 | 멘탈 계열 카드의 등급 확률 |
| 체력 | 컨디션 소모 저항 | **행동력 총량** + 체력 계열 등급 확률 |
| 인맥 | 엔딩 판정 조건 | **리롤 횟수** + 인맥 계열 등급 확률 |

다섯 스탯이 전부 매 턴 체감된다. 스탯은 홈 화면에 칩으로 상시 노출한다.

### 2.1 행동력

턴당 행동력은 포인트 예산이다. `cardsPerTurn`(재직 1장 / 퇴사 2장)을 대체한다.

```
행동력 = base + floor(체력 / staminaPerAP) + (퇴사 시 unemployedBonus)
```

`BALANCE.action`에 `base`, `staminaPerAP`, `unemployedBonus`를 둔다.
퇴사가 카드 장수가 아니라 행동력 보너스가 되는 편이 의미상 맞다 — 야근을 안 하니
한 주가 통째로 남는다.

### 2.2 카드 등급

카드는 슬롯에 뽑힐 때 **등급이 함께 굴려진다.** 성장해서 굳는 레벨이 아니다.

등급 `E · D · C · B · A · S` 여섯 단계. 등급이 오르면 효과 배율과 행동력 소모, 컨디션
소모가 함께 오른다. 같은 카드가 이번 주엔 A로, 다음 주엔 D로 뜬다.

```
효과   = 기본효과 × gradeMul[등급]
행동력 = gradeAp[등급]
컨디션 = 기본소모 × gradeMul[등급]
```

`BALANCE.grade`에 `gradeMul`·`gradeAp`와 등급별 기본 확률을 둔다.
대응 스탯이 높을수록 높은 등급 쪽으로 확률 질량이 이동한다 — 초반엔 E·D만 뜨고
후반엔 A·S가 섞인다.

**등급 굴림은 시드된 RNG를 통과한다.** 결정론은 이 프로젝트의 불변식이다.

### 2.3 슬롯과 리롤

```
회복 슬롯 1칸 : 휴식 / 운동 / 최존버와 소주 중 하나
행동 슬롯 3칸 : 성장 6종 + 야근 중 셋
```

**회복 슬롯은 행동력을 소모하지 않는다.** 1차 설계의 불변식("회복 카드는 어떤 멘탈
값에서도 잠기지 않는다")이 슬롯 구조에서는 **"회복 슬롯은 항상 하나 열려 있다"**로
번역된다. 회복이 행동력을 먹으면 예산 0에서 같은 교착이 재발한다.

회복 카드는 여전히 컨디션이나 현금을 비용으로 낸다(`최존버와 소주`는 현금 4만·컨디션 8).

리롤은 행동 슬롯 3칸을 다시 굴린다. 회복 슬롯은 리롤 대상이 아니다.
횟수는 `rerollBase + floor(인맥 / networkPerReroll)`로 정하며 매 턴 리셋된다.
`rerollBase`가 없으면 인맥 0인 초반에 리롤이 아예 없어 슬롯 뽑기의 운을 완화할 수단이 사라진다.

### 2.4 카드 재편

12장 중 둘의 성격이 어긋나 있었다.

- **`물타기`** — 효과가 `averageDown` 하나뿐인 순수 매매 행위다. **종목 상세 화면의
  버튼으로 옮긴다.** 보유 중인 종목에서만 활성화되고, 누르면 현재 평단과 물탄 후 평단을
  보여준다. 주간 행동을 소모하지 않는다.
- **`존버`** — `멘탈 +2, 컨디션 +6`으로 실질은 미약한 회복인데 이름이 행동인 척한다.
  회복 풀에 흡수한다. "아무것도 안 한다"는 선택은 카드를 고르지 않고 턴을 넘기는 것으로
  표현한다.

남는 10장이 슬롯 뽑기의 풀이 된다(성장 6 + 야근 1 + 회복 3).

## 3. 화면 구조

기준 뷰포트 390×844. 모든 화면은 max-width 480px, 다크 테마, 터치 타깃 44px 이상.

### 3.1 홈

```
상단바      ☰ │ 3년차 14주 (D-142) │ 35,450,000원 │ ⓘ        56px
진행바      ▓▓▓▓▓▓▓░░░░░░░░░░░░░░░                          12px
──────────────────────────────────────────────────
캐릭터      [배경 레이어] + [인물 레이어]                    260px
스테이지                          ┌──────────┐
                                 │ 개미      │  ← 티어
                                 │ +15.0%   │  ← 투자 수익률
──────────────────────────────────────────────────
뉴스 티커   📰 원달러 환율 1400원 돌파                ▸      32px
──────────────────────────────────────────────────
스탯 칩     강인 2.1│체력 3.4│정보 1.8│분석 4.2│인맥 0.9     40px
게이지      멘탈 ▓▓▓▓░ 72     컨디션 ▓▓░░░ 41                28px
행동력      ⚡ ●●●○ 3/4              🔄 리롤 (2)             40px
──────────────────────────────────────────────────
카드 2×2    ┌───────────┐ ┌───────────┐
            │ 기업분석 Ⓐ │ │ 뉴스탐독 Ⓓ │              190px
            │ 분석력 +1.4│ │ 정보력 +0.2│
            │ ⚡3   ♥−16 │ │ ⚡1   ♥−3  │
            └───────────┘ └───────────┘
──────────────────────────────────────────────────
            [ 한 주 넘기기 ]                              56px
탭바        홈 · 시세 · 계좌 · 도감                        56px
```

**뉴스 티커.** 1차에서는 최근 8건을 세로로 쌓아 화면을 먹었다. 156턴 동안 312건이
나오므로 목록으로는 소화되지 않는다. 한 줄 티커로 줄이고, 탭하면 최근 8건이 시트로
올라온다. 증권 앱의 문법이기도 하다.

**흔들림 상태.** 멘탈 ≤ 29이면 캐릭터가 `shaken` 표정으로 바뀌고, HUD에 배지가 뜨며,
화면 가장자리가 붉게 한 번 맥동한다. 이성 카드가 잠기고 회복 슬롯은 열려 있다.

### 3.2 시세 · 종목 상세 · 계좌 · 도감

시세는 섹터 필터 + 종목 카드 리스트를 유지하되 카드에 스파크라인을 넣는다.
종목 상세에 **물타기 버튼**이 추가된다(2.4).
계좌와 도감은 레이아웃만 새 디자인 언어에 맞춘다.

## 4. 비주얼 노벨 오버레이

### 4.1 이벤트

```
┌──────────────────────────────┐
│ 제목 배너                     │
│                              │
│   [배경 레이어]               │
│   [화자 스탠딩 스프라이트]      │
│                              │
│ ┌──────────────────────────┐ │
│ │ [이름표]                  │ │
│ │ 대사가 타이핑되어 나타난다.   │ │
│ │                          │ │
│ │ ⚠  ≫                  ≡ │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 이름표는 화자별 고정 색. 정체를 감춘 등장은 `???`로 표시한다 —
  김실장의 첫 등장("첫 두 번은 실제로 맞춘다")과 정확히 맞는 장치다.
- 화자가 없는 뉴스형 이벤트는 인물 자리에 섹터 아트나 시황 그래픽이 들어간다.
- `≫`는 타이핑 즉시 완성, `≡`는 로그, `⚠`는 이 이벤트가 가진 위험 표시.

### 4.2 선택지

대사를 읽고 나면 하단에서 시트가 올라온다. 질문 제목 + 선택지 버튼 세로 스택.
"결정하는 순간"을 대사와 분리하는 것이 목적이다.

**`resolveChoice`는 절대 던지지 않는다**(1차 불변식). 모달이 잘못된 인자를 넘겨도
조용히 아무 일도 일어나지 않으므로, 선택 후 `pendingChoices`가 실제로 비었는지
확인하는 것이 UI의 책임이다.

### 4.3 컷신

티어 승급·강등. 배경이 바뀌는 연출로 간다.
키는 `cutscene.promote.{1..5}` + `cutscene.demote.{0..4}` 10종(1차 Ruling 54).

### 4.4 엔딩 — 증권사 잔고증명서

1차 엔딩은 이모지 배지에 숫자를 얹은 카드였다. **실물 문서를 흉내낸다.**

```
        ─── 잔  고  증  명  서 ───
  계좌번호   000-00-000000
  예금주     김흑우
  ──────────────────────────────
  예수금             31,311,114 원
  주식평가금액         3,308,610 원
  평가금액 합계       34,619,724 원
  ──────────────────────────────
  3년 요약
    최고 자산         42,180,000 원
    최대 낙폭            −18.4 %
    총 거래 횟수            47 회
    낸 수수료·세금       412,880 원
  ──────────────────────────────
  2026. 08. 26.        [ 도장 ]

        은행 이자보단 낫지
     누구한테 자랑하긴 애매한 숫자.
```

**낸 수수료·세금 총액**을 노출하는 것이 이 게임의 자조적 톤과 특히 맞는다.
1차에서 수수료는 경제의 뒷받침이었으나 플레이어에게 한 번도 보이지 않았다.
이를 위해 `GameState.trackers`에 누적 수수료·세금, 최고 자산, 최대 낙폭,
거래 횟수를 추가한다.

칭호는 문서 하단에 도장 옆 라벨로 배치한다.

**실존 증권사의 상호·로고·서식을 쓰지 않는다.** 잔고증명서라는 문서 *형식*은 업계 공통이며
누구의 것도 아니지만, 특정 증권사의 양식을 재현하면 §7과 같은 종류의 위험이 생긴다.
발행처는 가상의 이름을 쓰고, 계좌번호는 `000-00-000000`처럼 마스킹된 형태로 둔다.

## 5. 아트 슬롯 규격

이미지는 사용자가 외부 AI 도구(ChatGPT·Gemini·Grok)로 생성해 순차 교체한다.
**슬롯은 이미지가 없어도 완결된 화면으로 보이도록 설계한다** — 실루엣, 그라디언트,
타이포그래피로 채우고, 이미지가 하나씩 들어올 때마다 좋아진다.

| 슬롯 | 비율 | 개수 | 용도 |
|---|---|---|---|
| `char.tier{0..5}.{normal,shaken,joy}` | 3:4 | 18 | 홈 캐릭터 스탠딩 |
| `npc.{daebak,cho,kim,mom}.{normal,alt}` | 3:4 | 8 | 이벤트 화자 |
| `bg.{office,home,street,exchange}` | 16:9 | 4 | 배경 레이어 |
| `cutscene.{promote,demote}.*` | 4:3 | 10 | 티어 전환 |
| `ending.*` | 1:1 | 8 | 엔딩 문서에 찍히는 도장 그래픽 (엔딩별로 다른 도장) |
| `sector.*` | 1:1 | 8 | 섹터 아이콘 |

인물 스프라이트는 **투명 배경(알파)** 을 전제한다. 생성 도구가 알파를 지원하지 않으므로
프롬프트에 **순수 마젠타(#FF00FF) 단색 배경**을 지정하고, 사용자가 키잉하여 첨부한다.
그림자를 배경에 드리우지 않도록 프롬프트에 명시한다 — 가장자리가 지저분해진다.

프롬프트는 별도 문서로 관리하며, **화풍 고정 문장을 모든 컷에 토씨 하나 바꾸지 않고
반복**한다. 생성 도구가 셋으로 갈리므로 그것이 유일한 일관성 장치다.

## 6. 애니메이션

세 층으로 나눈다. 전부 `prefers-reduced-motion`을 존중하고 스킵 옵션을 둔다.
156턴을 도는 게임에서 매번 기다리게 하면 짐이 된다.

**상태 전이** — 자산 숫자 롤업, 게이지 보간, 스탯 칩 증가 플래시.
지금은 값이 즉시 바뀌어 무엇이 변했는지 알 수 없다.

**화면 전환** — 오버레이 슬라이드업, 대화창 페이드인, 컷신 크로스페이드, 탭 전환 슬라이드.

**타격감** — 카드 프레스, 행동력 점 소모, 막힌 동작(손절 봉인)의 짧은 흔들림,
흔들림 진입 시 화면 가장자리 맥동.

**대사 타이핑** — VN의 기본. 탭하면 즉시 완성.

## 7. 종목명 가상화

1차 종목명은 실존 상장사와 1:1로 대응했고(`HD한국조선해왕`, `KB금융지붕`),
게임이 특정 종목을 확정 손실이나 함정으로 묘사하므로 상표·영업비방 위험이 있다.

KRX 상장법인목록(2,761개 회사명)과 대조하여 **완전일치 0건, 어근 충돌 0건**인
이름으로 교체한다.

| 섹터 | 기존 | 신규 |
|---|---|---|
| 반도체 | 삼정전자 | 윤슬반도체 |

| 바이오 | 한알바이오 | 나린바이오 |

ETF 둘(`레버리지ETF`·`곱버스ETF`)은 일반명사·업계 은어이므로 유지한다.
이벤트 본문의 실명 6곳(에코프로 3, 두산 3)도 함께 교체한다.

**어근을 전부 순우리말로 통일한 것은 우연이 아니다.** 실존 상장사는 대부분 한자어나
영어 어근을 쓰므로, 순우리말 어근은 충돌 확률이 구조적으로 낮다. 향후 종목 추가 시에도
같은 규칙을 적용한다.

상장법인목록을 `packages/core/data/listed-companies.json`으로 저장하고,
**대조를 테스트로 고정한다** — 스크립트가 아니라 테스트여야 앞으로 종목을 추가할 때마다
자동으로 걸린다. 목록 갱신 방법은 README에 남긴다.

## 8. `@bb/core` 변경 범위

이 재설계는 core를 건드린다. 1차에서 610개 테스트로 고정된 영역이므로 명시한다.

- `types.ts` — `CardGrade`, 슬롯 상태, 행동력, 확장된 `trackers`
- `balance.ts` — `action`, `grade`, `reroll` 블록 신설. 기존 `mood`(캐릭터 표정 구간)는
  스탠딩 스프라이트로 바뀌면서 임계를 다시 잡는다
- `turn/cards.ts` — 등급 굴림, 슬롯 뽑기, 리롤
- `turn/advance.ts` — `cardsPerTurn` → 행동력 예산, 슬롯 생성 단계 추가
- `turn/trade.ts` — `averageDown`을 카드 효과에서 매매 함수로
- `data/cards.json` — 물타기·존버 제거, 등급 기본값
- `data/stocks.json` — 종목명 8종
- `data/events/*.json` — 실명 6곳
- `data/listed-companies.json` — 신규

**결정론은 유지된다.** 등급 굴림과 슬롯 뽑기는 `GameState.rng`를 통과하며,
같은 시드가 156턴을 바이트 단위로 재현하는 성질은 회귀 테스트로 계속 고정한다.

밸런스 게이트는 다시 잡아야 한다 — 행동력과 등급이 성장 속도를 바꾸므로
`@bb/sim`의 6전략과 게이트 14개가 함께 움직인다.

## 9. 비목표

- **이벤트 콘텐츠 확대** — 76종을 유지한다. 연출만 바꾼다.
- **신용거래 UI** — 1차 Ruling 62·71로 보류된 사안이다. 파산·파이어족 엔딩 도달
  가능성은 별도 판단이 필요하다.
- **사운드** — 이번 범위 밖.
- **이미지 생성** — 사용자가 외부 도구로 수행한다. 이 스펙은 슬롯과 프롬프트까지만 정한다.
